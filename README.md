# 数学ハンター ― 六つの理石と、新しい朝

数式を解いて狩りをし、村を復興するブラウザの冒険RPGです。
本編18章・61依頼と仲間の外伝12話を通して、Blenderで作った50種のモンスター（大型38種・道中の小型12種）と戦います。

**[ブラウザで遊ぶ（スマホ対応）](https://dora9991.github.io/math-hunter/)**

## 遊び方

公開ページで「タップ／クリックしてはじめる」を押すと、物語の導入からリュミエ村へ進みます。村の「依頼を確認する」または「世界地図」から依頼を選び、痕跡・仕掛けを調べ、装具と難易度を決めて出発します。勝つと素材を受け取り、村で報告を聞けます。オフラインではビルド後の `dist/hunter.html` を開いて遊べます。`docs/index.html` を使う場合は `docs/assets/audio` も同じ場所に置いてください。

スマホでは画面下の6つの行動から1つ選び、大きな4択ボタンで答えます。地点番号を選んで移動の問題を解き、攻撃予告から逃げるか、回避を選んでください。「集中」をタップすると敵の動きが遅くなります。縦画面と横画面の両方に対応しています。

**10問正解で必殺ゲージが満タン**になります。青い必殺ボタン（パソコンではFキー）で「星解・六灯連斬」を発動できます。左右の部位と頭へ3連撃、ふつうでは基本合計680ダメージに難易度・装具補正。敵の予告・追撃も中断できます。発動でゲージを全消費し、再び正解を重ねるともう一度使えます。誤答でゲージは増えません。

ボス依頼は **道中の小型魔獣2戦 → ボスとの決戦**。中継地点では時間が止まり、体力・回復薬・集中・必殺ゲージを引き継いで次へ進みます。道中の素材はその場で保存され、撤退やボス戦での敗北でも失いません。本編の依頼は最後の相手を倒したときに達成となります。必殺ゲージは新しい依頼では0から始まります。自由狩猟・異変討究は選んだ魔獣との直接対戦です。

## 冒険と村の復興

数や図形の法則を宿す「理石」の異変を追い、帰ってこなかった調査隊の足跡をたどります。依頼は順に開放され、どの難易度でも物語が進みます。章の最後の依頼を達成すると村の施設が完成し、村の絵も変わります。

| 地域 | 村に戻る施設 | 冒険への支援 |
|---|---|---|
| 草原 | 鍛冶屋 | 素材で装具を製作できる |
| 森林 | 薬草園 | 回復薬 +1 |
| 砂漠 | 市場 | ギルド貨 +20% |
| 雪国 | 診療所 | 最大体力 +15 |
| 山頂 | 観測所 | 集中 +2秒 |
| 火山 | 六灯の広場 | 第一部クリア、第二部と異変討究の開放 |

調査は依頼画面で行います。痕跡を読むとその依頼で部位への蓄積が15%増え、仕掛けを解くと集中が2秒長くなります。どちらも任意で、調査記録は再挑戦でも使えます。仕掛けにはヒントがあり、誤答による素材の減少はありません。

鍛冶屋には、最初の装具を含めて8種類の装具があります。部位破壊・回避後の反撃・集中時間・守りに特徴があります。第7・8・9・11章の達成で「潮鎧の守護具」「双鎌の解体具」「砂時計の羅針具」「星環の決闘衣」が製作可能になります。各装具は最大＋5まで強化でき、1段ごとに基本の攻撃倍率が3.5%、体力が2、集中が0.4秒増えます。＋3以降はギルド勲章、＋4以降は古代核も必要です。

素材は勝利時に自動で受け取り、部位破壊で理石のかけらが増えます。達成済みの依頼は初回の40%の報酬で再挑戦できます。敗北で所持素材は減りません。

狩猟図鑑には冒険で出会った敵、観察した攻撃、壊した部位、討伐数と最速記録が残ります。村のミラ・ガン・トーマ・ナギと話し、依頼達成後の報告で物語を読み進められます。達成済みの依頼画面から、その物語を読み返せます。

冒険の進行・素材・装具・強化・外伝・調査・図鑑・評価・討究Lv・称号・道中討伐数・必殺回数は `hunter.adventure.v1` として端末のブラウザに自動保存されます。以前の13依頼をクリアしたセーブは第7章、37依頼をクリアしたセーブは第13章から続けられます。戦闘や中継地点の途中からの再開には対応していません。従来のバトル記録・設定は別の保存領域を使います。

## 自由狩猟と数式バトル

「自由狩猟」では、敵・背景・9つの戦闘設定を選べます。冒険の支援や装具は適用されず、物語の進行にも影響しません。「記録」には難易度ごとの最速・単元ごとの正解とミスが残ります。

対戦相手は50種から選べます。ザルヴァ・セクトラ・ヴェイラ、第一部の10体に加え、第二部には潮鎧蟹タラッサ、雷鰭竜ヴォルティス、菌灯獣ミセリア、刃螳獣シルヴァーク、砂時計獣アモル、碑翼竜オシロン、霜冠鹿ニヴァリス、氷狼獣フェンリグ、黒翼鴉コルヴェクス、星環竜エーテリオン、重鎧巨獣ガルガント、境界竜オラクレスが登場します。

第三部では鉄角犀ロクサル、島甲亀ケロナ、絹糸蜘蛛アラクナ、流刃蛇セイルーン、夢尾狐ヴルピラ、月翅蛾モスリア、鉱毒蠍スコルヴェクス、太陽竜ソルヴィル、風冠鷲グリフォル、鐘翼蝠ノクティラ、雷嵐鳥テンペストラ、霧牙巨象マンモラ、創星竜アストラヴォルを追加しました。小型12種は雷尾小獣・石棘猪・灯茸・葉羽虫・砂潜蛇・砂甲虫・雪跳兎・氷子狼・風小鴉・星蝙蝠・灰蜥蜴・火玉獣。体格・体力・攻撃力を下げ、道中で正解と必殺技の準備を積める相手にしています。追加25種にはそれぞれ3技、計75技があります。

追加種はそれぞれ体格・左右の移動幅・固有技3種を持ちます。鋏の挟撃、甲殻の横走り、蛇行、潮の波、胞子の発光、遠吠え、星環の回転、空からの急襲などの動きが加わりました。予告は単体・隣接・前方・背後・遠方・全地点に分かれ、二段・三段攻撃もあります。頭部、左右の装甲・鰭・翼、尻尾を破壊できます。左右両方を壊すと、その敵の大技を封じられます。飛行種は翼が壊れると高度が下がります。URLから直接始める場合は `?math=1&enemy=thalass` のように指定します。

戦う背景は **火山・草原・雪国・森林・砂漠・山の上** の6種類です。空・地面・遠景の岩山や木などを切り替えます。拠点の「戦う背景」で自由に選べるほか、「おすすめ」では敵に合わせて自動選択します。URLからは `?math=1&enemy=frostra&background=snowland` のように指定できます（`volcano` / `grassland` / `snowland` / `forest` / `desert` / `summit`）。

BGM 8曲を仮配置しました。タイトル画面の「タイトル曲を聴く」でタイトル曲、数式バトルの準備画面で「戦闘よび」、記録・設定などの拠点メニューで「メニュー画面」が流れます。通常戦闘は「中1の通常戦闘」、強敵と「むずかしい」は「中3の通常戦闘」、ザルヴァ・セクトラ・ヴェイラ・ガルド・バルザ・ルナクスは「章のボス」です。討伐成功と失敗ではそれぞれ勝利・敗北曲へ切り替わります。設定の BGM で消音できます。公開版は曲を必要なときに読み込み、`dist/hunter.html` の1ファイル版には音源を同梱しています。

編集用モデルは `tools/blender/out/*.blend`、ゲーム用モデルは `assets/models/monster/*.glb` にあります。追加47体は `tools/blender/bestiary_build.py` を `-- raizen` のようにIDを指定して再生成できます。第二部12体は `Blender --background --python tools/blender/build_expansion.py`、第三部と道中の25体は `Blender --background --python tools/blender/build_frontier.py` でまとめて再生成できます。

拠点メニューの「自由狩猟」から。`dist/hunter.html?math=1` を開くと、前回の設定ですぐ始まる（`?math=1&level=beginner|easy|normal|hard` で難易度を指定）。

- 行動のカードごとに、問題と**4つの答え**が出ている。**正しい答えを1回タップ（クリック）した瞬間に、その行動が出る**。
- はずれを選ぶとミス：正解が緑で示され、1秒動けず、連続正解が0に戻る。そのカードは新しい問題に替わる。まちがえた問題は結果画面に一覧で残る。
- 4つの答えには「よくある間違い」（符号の取り違え、計算の順番、移項の符号など）を混ぜてある。「左へ／右へ」は4つとも同じ符号（符号だけでは当てられない）。
- 設定の「答え方」を「数字を打つ」にすると、以前の形（数字と「−」のキーで答えを入力）になる。
- **時間は止まらない。** 敵は「予告（赤い円とカウント）→攻撃」をくり返す。間に合わなければダメージ。
- 立ち位置は敵ごとに3〜5地点。番号を選び、移動の問題に正解すると目的地へ移動。正面は頭、側面は脚・翼・装甲、背後は尾を狙える。退避・遠方は剣と必殺技が届かない。
- 斬る＝正負の乗除／溜め斬り＝一次方程式／左へ・右へ＝正負の加減（左は答えが負、右は正）／回避＝敵の攻撃が強いほど難しい／回復＝式の値（3回）。
- 連続で正解すると攻撃が強くなる（最大1.5倍）。回避に成功すると次の一撃が1.5倍。
- **必殺技**：正解1問でゲージ＋10、満タン100で「星解・六灯連斬」。ボタンまたはFキーで発動。道中からボスへ温存できます。
- **スロー（集中）**：スペースキー（または左上の「集中」ボタン）で世界がゆっくりになる。ゲージのぶんだけ使え、正解で8%、使っていない間は60秒で満タンまで戻る。答えを打つ速さは変わらないので、考える時間をかせげる。
- **難易度**：入門・小学生／やさしい／ふつう／むずかしい／カスタム。カスタムでは9項目を個別に選べる。

### 地点と魔獣ごとの戦術

50体の配置は **3地点17体／4地点10体／5地点23体**。小型は3地点、岩甲獣グラドンなどは4地点、刃螳獣シルヴァーク・飛行種などは5地点です。

| 戦術 | 攻め方・避け方 |
|---|---|
| 装甲・巨体 | 正面の与ダメージは×0.35。側面・背後を使うか、攻撃直後3.8秒の隙に正面へ（×1.60）。巨体は体力と一撃も強い |
| 高空・低空 | 8秒高空→6秒低空を繰り返す。高空は正面・背後から届かず側面の翼を狙う。片翼破壊で高空を封じ、低空の正面は×1.30 |
| 追尾 | 予告が居場所を追う。「照準固定」の後に移動、または回避の問題を解く |
| 三段攻撃 | 前方3地点→背後→遠方と順番に狙う。各段に2.25秒の予告と回避問題がある |
| 残留攻撃 | 攻撃地点に6秒間、紫の危険が残る。同じ地点では1.5秒ごとに追加ダメージ |
| 退避・遠方 | 近接攻撃の範囲外。ただし剣と必殺技も届かず、遠距離攻撃は追ってくる |

背後は尾に×1.15。切断後は攻撃が届かなくなるため別の地点へ。必殺技は届く地点で発動すると高空と装甲を5秒間崩し、追撃も止められます。敵の体力・攻撃・予告の長さには生態ごとの補正も加わります。出発前の依頼画面と自由狩猟に地点数・戦術・補正を表示します。

## できること

- **大剣**：抜刀斬り・縦斬り・なぎ払い・斬り上げのコンボ、長押しの溜め斬り（3段階・溜めすぎあり）、刀身でガード（咆哮もガードできる）
- **太刀**：踏み込み斬り・縦斬り・突き・斬り上げ・斬り下がり、気刃ゲージ（当てるとたまる／満タンで攻撃力アップ）、気刃斬りI→II→III→気刃大回転斬り
- ハンター：体力（赤ゲージは時間で少し戻る）・スタミナ（ダッシュ・回避で減る。0で息切れ）・切れ味（色で威力が変わる。低いと硬い所で弾かれる）、前転の無敵時間、攻撃後の回避キャンセル、吹っ飛び・受け身、咆哮で耳をふさぐ、足踏みでよろける
- アイテム：回復薬（飲んだあとのガッツポーズつき）・上回復薬・砥石・閃光弾・ペイント玉・雷撃罠
- モンスター：徘徊 → 発見して咆哮 → 噛みつき・尻尾回転・突進（通り過ぎて振り返る）・飛びかかり・火球・足踏み。すべて予備動作あり
  - 怒り（目が赤く光り、速く強くなる）→ 疲労（よだれ・火球の不発）
  - 部位ごとの肉質、怯み、脚への蓄積で転倒、**頭の部位破壊（角が折れる）**、**尻尾切断（切れた尻尾から剥ぎ取れる）**
  - 体力が半分を切るとエリア移動、瀕死で足を引きずって**エリア4の巣**へ逃げて眠る（寝ている所への一撃は2倍）
  - 閃光弾で目くらまし、雷撃罠でしびれる、ペイントで地図に表示
- 狩り場：番号つきの4エリア＋ベースキャンプ、湖、竜の巣、遺跡の柱
- 手触り：ヒットストップ、ヒットの火花と衝撃の輪、ダメージ数値、画面揺れ、剣の軌跡、合成した効果音とユーザー提供のBGM
- 拠点：クエスト受注（難しさ3段階）、装備、アイテムボックス（剥ぎ取った素材がたまる）、操作説明、設定、クレジット
- 設定：マウス感度・上下反転・マウスカメラのオン/オフ・音量・BGM・画質（軽い/ふつう/きれい）・ダメージ数値・モンスターの体力表示（初期は非表示）

## 見た目と重さ（2026-10-01 夜に作り直し）

- 竜とハンターは Blender で作ったモデル。地面・崖・砂・樹皮は写真ベースの質感画像。木と茂みは「幹＋葉の板」。エフェクトは絵つきの粒（炎・煙・火花の筋・閃光・焦げ跡）。
- 設定の「画質」は、描く画素数の上限（軽い 65万／ふつう 100万／きれい 160万画素）と草の量・影の細かさを変える。初期値は「ふつう」。
- 「光のにじみ」は初期オフ（オンにすると炎や火花がにじんで光るが、少し重くなる）。
- 目安：Safari のエンジンで1コマ約11ミリ秒（ふつう・960×600の窓）。

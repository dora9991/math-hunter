# 竜狩りの谷 ― 数式バトル

ブラウザで遊ぶ3Dの数式バトルです（非公式のファンメイド作品）。
数式を解いて、Blenderで作った13体のモンスターと戦います。

**[ブラウザで遊ぶ（スマホ対応）](https://dora9991.github.io/math-hunter/)**

## 遊び方

公開ページをブラウザで開き、「タップ／クリックしてはじめる」→「数式バトル」から敵と難易度を選びます。オフラインでは `docs/index.html` またはビルド後の `dist/hunter.html` を開いて遊べます。

スマホでは画面下の6つの行動から1つ選び、大きな4択ボタンで答えます。攻撃予告を見て左右に移動するか、回避を選んでください。「集中」をタップすると敵の動きが遅くなります。縦画面と横画面の両方に対応しています。

## 数式バトル（これが本体）

2026-10-02 から、このゲームは数式バトル専用。自分で操作する「ふつうの狩り」はメニューから外した（中の仕組みは数式バトルの土台として残してある）。拠点の「記録」に、難易度ごとの最速・単元ごとの正解とミスが残る。

対戦相手は13体から選べます。既存のザルヴァ・セクトラ・ヴェイラに加え、ライゼン、グラドン、モルガ、フロストラ、サルダ、ヴェルム、ネブラ、ガルド、バルザ、ルナクスを追加しました。新しい10体はそれぞれ専用フィールド、異なる立ち位置の幅、固有技3種を持ちます。予告は単体・隣接2か所・左右・中央・全域に分かれ、一部は二段攻撃です。頭部、左右の装甲・鰭・翼、尻尾を破壊できます。左右両方を壊すと、その敵の大技を封じられます。飛行種は翼が壊れると高度が下がります。URLから直接始める場合は `?math=1&enemy=raizen` のように指定します。

編集用モデルは `tools/blender/out/*.blend`、ゲーム用モデルは `assets/models/monster/*.glb` にあります。新しい10体は `tools/blender/bestiary_build.py` を `-- raizen` のようにIDを指定して再生成できます。

拠点メニューの「数式バトル」から。`dist/hunter.html?math=1` を開くと、前回の設定ですぐ始まる（`?math=1&level=easy|normal|hard` で難易度を指定）。

- 行動のカードごとに、問題と**4つの答え**が出ている。**正しい答えを1回タップ（クリック）した瞬間に、その行動が出る**。
- はずれを選ぶとミス：正解が緑で示され、1秒動けず、連続正解が0に戻る。そのカードは新しい問題に替わる。まちがえた問題は結果画面に一覧で残る。
- 4つの答えには「よくある間違い」（符号の取り違え、計算の順番、移項の符号など）を混ぜてある。「左へ／右へ」は4つとも同じ符号（符号だけでは当てられない）。
- 設定の「答え方」を「数字を打つ」にすると、以前の形（数字と「−」のキーで答えを入力）になる。
- **時間は止まらない。** 敵は「予告（赤い円とカウント）→攻撃」をくり返す。間に合わなければダメージ。
- 立ち位置は左・中央・右。中央は頭（弱点）を斬れるが、噛みつきと火球が来る。左右は脚を斬って転ばせられる。
- 斬る＝正負の乗除／溜め斬り＝一次方程式／左へ・右へ＝正負の加減（左は答えが負、右は正）／回避＝敵の攻撃が強いほど難しい／回復＝式の値（3回）。
- 連続で正解すると攻撃が強くなる（最大1.5倍）。回避に成功すると次の一撃が1.5倍。
- **スロー（集中）**：スペースキー（または左上の「集中」ボタン）で世界がゆっくりになる。ゲージのぶんだけ使え、正解で8%、使っていない間は60秒で満タンまで戻る。答えを打つ速さは変わらないので、考える時間をかせげる。
- **難易度**：やさしい／ふつう／むずかしい／カスタム。カスタムでは8項目を個別に選べる。

| 項目 | 選べる値 | やさしい | ふつう | むずかしい |
|---|---|---|---|---|
| 答え方 | 4択をタップ・数字を打つ | 4択 | 4択 | 4択 |
| 敵の速さ（予告と間合い） | ゆっくり・ふつう・はやい | ゆっくり | ふつう | はやい |
| 問題の難しさ | やさしい・ふつう・むずかしい | やさしい | ふつう | むずかしい |
| スローの長さ | なし・3・6・12・20秒 | 12秒 | 6秒 | 3秒 |
| スローの強さ | 0.6・0.4・0.25倍速 | 0.25 | 0.4 | 0.6 |
| スローの出し方 | スペースキー・危ないとき自動 | 自動 | キー | キー |
| 敵の攻撃力 | 弱い(0.4)・ふつう・強い(1.4) | 弱い | ふつう | 強い |
| 敵の体力 | 少ない(0.5)・ふつう・多い(1.4) | 少ない | ふつう | 多い |

問題の難しさ：やさしい＝小さい数・1手の方程式（x + b = c、ax = c）／ふつう＝正負の乗除・ax + b = c／むずかしい＝3つの数の計算・2乗・両辺にかっこのある方程式。調整する場所は `js/mathbattle.js` の `OPTIONS`・`PRESETS` と `js/mathproblems.js` の `KINDS`。

確認：`node tests/view.cjs chrome mathtest`（57項目）、`mathbot`（自動プレイで勝ち負け）、`math`／`mathui`（画面）、`smooth`（動きのなめらかさの計測）。`webkit` でも同じ。

## できること

- **大剣**：抜刀斬り・縦斬り・なぎ払い・斬り上げのコンボ、長押しの溜め斬り（3段階・溜めすぎあり）、刀身でガード（咆哮もガードできる）
- **太刀**：踏み込み斬り・縦斬り・突き・斬り上げ・斬り下がり、気刃ゲージ（当てるとたまる／満タンで攻撃力アップ）、気刃斬りI→II→III→気刃大回転斬り
- ハンター：体力（赤ゲージは時間で少し戻る）・スタミナ（ダッシュ・回避で減る。0で息切れ）・切れ味（色で威力が変わる。低いと硬い所で弾かれる）、前転の無敵時間、攻撃後の回避キャンセル、吹っ飛び・受け身、咆哮で耳をふさぐ、足踏みでよろける
- アイテム：回復薬（飲んだあとのガッツポーズつき）・上回復薬・砥石・閃光弾・ペイント玉・雷撃罠
- モンスター：徘徊 → 発見して咆哮 → 噛みつき・尻尾回転・突進（通り過ぎて振り返る）・飛びかかり・火球・足踏み。すべて予備動作あり
  - 怒り（目が赤く光り、速く強くなる）→ 疲労（よだれ・火球の不発）
  - 部位ごとの肉質、怯み、脚への蓄積で転倒、**頭の部位破壊（角が折れる）**、**尻尾切断（切れた尻尾から剥ぎ取れる）**
  - 体力が半分を切るとエリア移動、瀕死で足を引きずって**エリア4の巣**へ逃げて眠る（寝ている所への一撃は2倍）
  - 閃光弾で目くらまし、雷撃罠でしびれる、ペイントで地図に表示
- 狩り場：番号つきの4エリア＋ベースキャンプ、湖、竜の巣、遺跡の柱
- 手触り：ヒットストップ、ヒットの火花と衝撃の輪、ダメージ数値、画面揺れ、剣の軌跡、合成した効果音とBGM（戦闘中は戦闘曲）
- 拠点：クエスト受注（難しさ3段階）、装備、アイテムボックス（剥ぎ取った素材がたまる）、操作説明、設定、クレジット
- 設定：マウス感度・上下反転・マウスカメラのオン/オフ・音量・BGM・画質（軽い/ふつう/きれい）・ダメージ数値・モンスターの体力表示（初期は非表示）

## 開発版の動かし方

```bash
node tests/devserver.cjs 5190
```

http://localhost:5190/ を開く（JSファイルを分けたまま動きます）。
`?debug=1`、`?seed=数字`（乱数を固定）、`?autotest=1`（通しの自動テスト40項目）を付けられます。

- 配布版をつくる：`npm install` のあと `node build.mjs` → `dist/hunter.html`
- 計算まわりのテスト：`node tests/run.cjs`（109項目）

## 見た目と重さ（2026-10-01 夜に作り直し）

- 竜とハンターは Blender で作ったモデル。地面・崖・砂・樹皮は写真ベースの質感画像。木と茂みは「幹＋葉の板」。エフェクトは絵つきの粒（炎・煙・火花の筋・閃光・焦げ跡）。
- 設定の「画質」は、描く画素数の上限（軽い 65万／ふつう 100万／きれい 160万画素）と草の量・影の細かさを変える。初期値は「ふつう」。
- 「光のにじみ」は初期オフ（オンにすると炎や火花がにじんで光るが、少し重くなる）。
- 目安：Safari のエンジンで1コマ約11ミリ秒（ふつう・960×600の窓）。
